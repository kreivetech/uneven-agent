# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Uneven Agent**, please **do not** open a public GitHub Issue.

Instead, report it privately via one of the following channels:

- **Email:** `contact@kreive.com.br`
- **GitHub Security Advisories:** Use the **Report a vulnerability** option under the **Security** tab of `kreivetech/uneven-agent` (when enabled).

Please include:

- A clear description of the vulnerability and potential impact.
- Step-by-step instructions or a minimal proof of concept to reproduce the issue.
- The affected version or commit hash.

We will acknowledge receipt and work on a fix before any public disclosure.
